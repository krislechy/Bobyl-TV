# Работа с агентами Bobyl TV

Начало: [общий контракт](../AGENTS.md) и нужный маршрут [карты контекста](CONTEXT.md).
Перед изменением кода — [соглашения](CONVENTIONS.md) и одна профильная роль.
Набор хранится в Git вместе с проектом; родительский AGENTS.md — только указатель.

## Роли

| Роль | Когда нужна | Инструкция |
|---|---|---|
| orchestrator | Декомпозиция, контракты, интеграция, итог | [orchestrator](roles/orchestrator.md) |
| ui-tv | Compose, D-pad, focus, экраны, визуальное качество | [ui-tv](roles/ui-tv.md) |
| data | ViewModel, каталог, авторизация, сеть, хранение | [data](roles/data.md) |
| playback | Внешние плееры, relay, субтитры, прогресс | [playback](roles/playback.md) |
| reference | Проверка поведения оригинала по Java/smali | [reference](roles/reference.md) |
| reviewer | Независимая проверка рисков и регрессий | [reviewer](roles/reviewer.md) |
| build-verifier | Сборка, тесты, единственный доступ к ADB | [build-verifier](roles/build-verifier.md) |

## Запуск

Пример для оркестратора:

> Прочитай AGENTS.md, .ai/roles/orchestrator.md и .ai/ORCHESTRATION.md.
> Задача: исправить восстановление focus после закрытия карточки.
> Декомпозируй только независимые части. Выбор модели оценивай, если он входит в задачу.

Пример независимого исполнителя:

> Прочитай AGENTS.md и .ai/roles/ui-tv.md.
> Задача и критерии: [описание].
> Разрешено менять только [точные пути]. Остальные файлы — чтение.
> Не запускай Gradle/ADB; верни diff, проверки и запросы на изменение контракта.

Для полноценной передачи используй [шаблон назначения](templates/TASK.md).
Инструкции позволяют выполнять роль в текущем агенте, субагенте или отдельной
уже созданной задаче. Они сами не создают задачи, не регистрируют custom agents
и не переключают модель. Фактический запуск определяется доступными инструментами.

## Порядок чтения

Малая задача: общий контракт → нужный маршрут → профильная роль для кода.
Для Markdown достаточно общего контракта и затронутых документов.
При делегировании добавь ORCHESTRATION и TASK; MODELS читай при выборе/оценке модели.
Не загружай весь каталог ролей каждому исполнителю.
