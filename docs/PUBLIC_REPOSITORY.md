# Публичный репозиторий и локальные данные

Проект перенесён в новый репозиторий с чистой историей. Личные адреса авторов
старых коммитов и прежняя закрытая история не переносились. В коммитах используется
публичный технический адрес GitHub noreply.

Не публикуются:

- оригинальные сторонние APK и декомпиляции;
- пароли, токены, cookies и файлы сессий;
- ключи подписи и их пароли;
- адреса личных устройств, локальные настройки и пути компьютера;
- пользовательская история просмотра и настройки приложения;
- рабочие логи, снимки экрана, локальная память инструментов и исходные макеты.

Список исключений закреплён в `.gitignore`. Перед публикацией выполнена проверка
новой истории и исходников сканером секретов и отдельный поиск личных адресов,
путей и сетевых настроек. Это не означает, что будущие изменения можно публиковать
без внимания к их содержимому.

Имена владельца GitHub и авторов сторонних компонентов, необходимые уведомления
об их правах и публичные адреса сервисов не являются данными пользователя приложения.
Они сохраняются там, где необходимы для работы проекта и уведомлений.

Адрес приставки хранится только в `BOBYL_TV_ADB` или локальном `bobyl.local.json`
в каталоге инструментов. Локальные APK, SDK и декомпиляции могут использоваться
разработчиком отдельно; они не входят в публичный репозиторий.
