# Бобыль TV 2.3.8

- Действия карточки перенесены в вертикальную колонку слева, включая кнопку возврата.
- Добавлены подсказки к иконкам при фокусе пульта.
- Избранное обозначается закладкой, личная оценка — звездой и баллом.
- Статусы просмотра и действия с ними получили иконки кинохлопушек.
- При ручной отметке просмотра предлагается оценить фильм.
- Окна оценки и избранного стали компактнее.
- Добавлена дата рядом с уменьшенными часами.
- Production умеет проверять, скачивать и устанавливать обновления из Releases нового репозитория.
- Перед установкой проверяются пакет, версия, SHA-256 и сертификат подписи APK.

Production: `com.bobyl.tv`, versionCode 56. Dev этим механизмом не обновляется.
Установите APK поверх предыдущей production-версии, сохраняя данные приложения.
Версии без встроенного обновления нужно один раз обновить вручную.
