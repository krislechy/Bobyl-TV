# Бобыль TV 3.0.0

Большое обновление интерфейса, локального хранения и загрузки данных.

## Интерфейс для телевизора

- Обновлённый стиль «Кинозал»: плавная рамка фокуса у постеров и групп кнопок, мягкий свет и анимации.
- Сворачиваемое левое меню с восстановлением выбранного раздела. Аккаунт закреплён внизу и открывается в компактном окне.
- Главная с приветствием по никнейму, сводкой аккаунта, продолжением просмотра и новинками.
- Баннер новых серий появляется только при наличии серий. Главная подготавливается за стартовой заставкой.
- Прогресс Premium учитывает подтверждённый оплаченный период.
- Карточки фильмов и сериалов расширены; исправлена навигация к списку серий ниже актёрского состава.
- Настройки расположены в две колонки: одиночные элементы слева, соседние — попарно. Обновление плееров, очистка кэша и сохранение зеркала доступны иконками рядом с полями.

## Данные и списки

- Локальные данные перенесены в Room с начальной инициализацией и импортом прежних записей.
- Личные оценки хранятся локально с разделением по аккаунтам.
- История объединяет записи аккаунта и устройства по фильму, сохраняет отметки источника и сортировку по последнему просмотру.
- Изменения конкретного фильма обновляют связанные записи и списки адресно.
- Избранное и категории сохраняют фильтры, страницы и позицию при возврате.
- Исправлены лишние повторные загрузки. Ручная очистка удаляет кэш данных и обновляет сохранённые списки при следующем открытии.

## Производительность и надёжность

- Тяжёлый разбор ответов и поиск установленных плееров выполняются вне главного потока.
- Сокращены лишние чтения БД и обновления интерфейса; сохранены визуальные эффекты.
- Усилена защита операций от поздних ответов, отмены и смены аккаунта.
- Улучшены обработка ошибок, повторные попытки и сохранение уже показанных данных во время обновления.

Production APK подписан прежним сертификатом и предназначен для обновления установленного приложения без удаления данных. Dev остаётся отдельным приложением.
