# Бобыль TV 2.3.11

- Добавлено восстановление открытой карточки, выбранной серии и данных запуска внешнего плеера после выгрузки приложения Android.
- При отметке фильма просмотренным после окна оценки предлагается удалить его из всех списков избранного. Удаление выполняется только после подтверждения и проверяется на сервере.
- Значок избранного в левом меню заменён закладкой.
- Устаревшие страницы обновляются после пробуждения устройства и по истечении срока кэша. При обновлении сохраняются видимое содержимое и положение списка.

Номер сборки: 59. Устанавливайте поверх предыдущей версии с сохранением данных.
