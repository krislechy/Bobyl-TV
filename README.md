# Бобыль TV

Приложение для Android TV: каталог фильмов и сериалов, поиск, избранное, комментарии,
оценки, история просмотра и запуск видео во внешнем плеере. Интерфейс рассчитан
на телевизор и управление пультом.

**Единственный актуальный репозиторий:** [krislechy/Bobyl-TV](https://github.com/krislechy/Bobyl-TV).

## Установка

1. Откройте [последний релиз](https://github.com/krislechy/Bobyl-TV/releases/latest).
2. Скачайте файл `bobyl-tv-production-v<версия>.apk`. Файл
   `bobyl-tv-update.json` используется приложением, устанавливать его не нужно.
3. Перенесите APK на телевизор или приставку и откройте его файловым менеджером.
4. При необходимости разрешите этому источнику установку приложений.
5. Для обновления уже установленного «Бобыля» установите APK поверх приложения.
   Удалять прежнюю версию и очищать данные не нужно.

Production использует пакет `com.bobyl.tv`. Dev — отдельное приложение
`com.bobyl.tv.dev`; оно устанавливается рядом и не заменяет production.

После первой установки выберите доступный вам адрес провайдера в настройках.
Для истории аккаунта, избранного и комментариев может потребоваться вход.
Видеоконтент и учётные записи в этот репозиторий не входят.

## Обновление через GitHub

В production откройте **Настройки → Обновление приложения → Проверить обновления**.
Если новая версия найдена, скачайте её и нажмите **Установить**. Последнее
подтверждение выполняет установщик Android.

Загрузка начинается только по вашему действию. Приложение берёт последний обычный
релиз из этого репозитория; черновики и предварительные релизы пропускаются.
Перед установкой проверяются SHA-256, имя пакета, более высокий номер версии,
отсутствие режима отладки и совпадение сертификата подписи.

В Dev, benchmark и profile этот механизм отключён.
Версии, выпущенные до появления обновления через GitHub, нужно один раз обновить
вручную до 2.3.8 или новее.

## Что умеет приложение

- Каталог, новинки, категории, поиск и карточки фильмов.
- Избранное и списки аккаунта.
- «Продолжить», просмотренные фильмы, локальная позиция воспроизведения.
- Оценки и комментарии.
- Выбор качества, озвучки, субтитров и внешнего плеера.
- Управление пультом, подсказки к иконкам и индикаторы загрузки.

Часть возможностей зависит от доступности провайдера, авторизации и поддержки
выбранного внешнего плеера.

## Сборка из исходников

Нужны Git, JDK 17 и Android SDK с платформой API 37. Точные версии зависимостей
заданы в Gradle-файлах; Gradle Wrapper входит в репозиторий.

```powershell
git clone https://github.com/krislechy/Bobyl-TV.git
cd Bobyl-TV
```

Укажите SDK в локальном `local.properties`, например:

```properties
sdk.dir=C:/Android/Sdk
```

Этот файл исключён из Git. Установите `JAVA_HOME` на JDK 17, затем соберите Dev:

```powershell
.\gradlew.bat --no-daemon :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
Для ручной установки в запущенный эмулятор:

```powershell
adb -s emulator-5554 install -r app/build/outputs/apk/debug/app-debug.apk
```

Для рабочего окружения с локальными инструментами доступна единая команда
сборки и установки Dev:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\BuildDev.ps1
```

## Локальное окружение

Вспомогательные скрипты используют каталог `.tools` рядом с репозиторием либо
путь из переменной `BOBYL_TOOLS_ROOT`. В нём ожидаются `android-dev/jdk-17`,
`android-dev/sdk` и `platform-tools/adb.exe`.

Адрес физической приставки задаётся только локально: переменной `BOBYL_TV_ADB`
либо полем `tvAdb` в файле `bobyl.local.json` внутри каталога инструментов.
Адресов реальных устройств в публичном проекте нет.
Не публикуйте этот файл, ключ подписи, cookies, пароли и данные сессий.

## Production и публикация релиза

[Полная инструкция по выпуску и обновлению](docs/TV_RELEASE.md).

Публикация выполняется только по отдельной команде. Для сохранения изменений,
проверки секретов, отправки исходников и выпуска обновления используется один скрипт:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\PublishGitHub.ps1 -NotesPath .\docs\releases\2.3.10.md -CommitMessage "Обновление интерфейса"
```

Нужны GitHub CLI с авторизацией и Gitleaks в PATH либо в каталоге инструментов
`privacy/gitleaks.exe`. При обнаружении личных данных или секретов отправка блокируется.

- Production APK: `app/build/outputs/apk/tvRelease/app-tvRelease.apk`.
- Пакет и существующий сертификат подписи необходимо сохранять.
- Номер `versionCode` каждого нового релиза должен увеличиваться.
- Ключ подписи хранится локально и не входит в репозиторий.
- Публикация APK не устанавливает его на физическую приставку.

## Структура проекта

- `app/` — Android-приложение и существующие тесты.
- `tools/` — локальные команды сборки, установки и публикации.
- `docs/` — инструкции и технические материалы.
- `DESIGN.md`, `PRODUCT.md` — оформление и назначение приложения.
- `AGENTS.md`, `.ai/` — правила работы с проектом.
- `macrobenchmark/` — существующие инструменты измерений; их запуск отдельно согласуется.

[Как исключены личные данные и оригинальный APK](docs/PUBLIC_REPOSITORY.md).

Тесты и технические проверки не заменяют проверку управления пультом.
Текущий разрешённый процесс работы описан в `AGENTS.md`.
